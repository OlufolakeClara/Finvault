# Finvault — Personal Finance Dashboard

Live Website: https://finvault-dashboard-3.vercel.app/

A comprehensive, high-fidelity personal finance web application designed to help users track net worth, manage budgets, analyze cash flows, log transactions, set savings goals, and view investment portfolios.

## 🛠️ Technical Features & Architecture
- **End-to-End Ownership:** Complete management of user experience flows, visual design system tokens, front-end architecture, and production deployment.
- **Data Visualization Matrices:** Interactive dashboard modules mapping financial metrics across net worth trajectory tracking and multi-tier budgeting models.
- **Modular Frontend Architecture:** Built with highly reusable component structures ensuring smooth data rendering across complex dynamic tables and portfolio views.

## 🧰 Technical Stack
- **Frontend Framework:** React, Next.js
- **State Management & Logic:** JavaScript (ES6+)
- **Deployment Infrastructure:** Vercel Pipeline
